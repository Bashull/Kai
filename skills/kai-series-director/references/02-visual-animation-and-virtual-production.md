# VISUAL · Dirección, fotografía, actuación, 2D, 3D y live action

## Paquete mínimo por plano
`shot_id`, blocking/planta de set, intencionalidad, lente/cámara/movimiento, focal y distancia motivadas, eje, sujeto activo, mirada, acción y contacto, props, textura, iluminación, continuidad ambiental, duración/beat y vecinos de corte. `camera.exception` con tipo `deliberate`, motivo y evidencia si se cruza el eje intencionalmente. Las reglas de 180°/30° son guías, no leyes físicas.

## Anime tradicional y animación digital
Separar layout, pose clave, timing, in-betweens, cleanup, color/ink, fondo, composición, animatic y render. OpenToonz/Blender Grease Pencil permiten control de timing y capas; IA puede asistir pero no reemplaza dirección de acting. Preservar hojas de modelo 360°, proporción, manos, pies, siluetas, turnarounds, mouth charts y ortografía de nombres.

## Actuación y mocap
Definir `goal / tactic / attention / thought-shift / pause / breath / action / reaction`, luego capture/retarget, cleanup, contacto de pies/manos, trayectorias, smoothing y QA de sincronía. FreeMoCap/LivePortrait/MuseTalk son research candidates, no sustitutos probados de la actuación. Animación labial requiere diálogo literal y alineación temporal real.

## 3D / producción virtual
USD para escenas y variantes, material/lookdev con MaterialX, Blender para rigs y previs, Unreal Sequencer/MetaHuman para etapas compatibles. El rodaje virtual tiene tracking, latencia, color de cámara/LED, óptica/distorsión, oclusión, eye line, iluminación y parallax; solo certificar ICVFX tras calibración real. Diferenciar simulación renderizada de set construido.

## Identity QA
No embellecer ni alterar rasgos protegidos, no inventar anatomía oculta; distinguir proyección perspectiva de medidas físicas. Crear anclas por personaje/época/estado, no usar el último fotograma como referencia automática. Mantener `shot_before` y `shot_after` para raccord.
