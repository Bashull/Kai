# KAI Nueve Reinos · Ojos del Mundo v0.2

Behavior Pack sensorial para Minecraft Bedrock.

- Consulta posición, dimensión, salud y hasta 16 entidades en 20 bloques.
- Publica `typeId`, vector relativo, vida y `minecraft:type_family`.
- Marca como amenaza familias `monster/hostile/enemy/undead/illager/boss` y hostiles vanilla conocidos.
- Publica snapshots, heartbeat, spawn, hurt y death con prefijo `KAI_EYES:`.
- No modifica bloques, entidades, inventario ni movimiento.

Termux consume los eventos mediante `kai-minecraft-worldbus`.

Diagnóstico recomendado: Settings → Creator → Content Log File.
